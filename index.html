Sobre Mí

Soy desarrollador de software con experiencia en la creación de aplicaciones de escritorio y web utilizando .NET Framework. Mi especialidad principal es el desarrollo con Windows Forms (WinForms), donde he construido aplicaciones completas para la gestión de datos, automatización de procesos y herramientas internas.

También cuento con experiencia en la creación de APIs REST con .NET, desarrollo web con ASP Clásico y PHP, y gestión de bases de datos con Microsoft SQL Server, MySQL y SQLite. Me considero un desarrollador práctico que busca soluciones eficientes a problemas reales.
