├── index.html      # Estructura principal del sitio

└── README.md       # Este archivo

## ✨ Características

- **Diseño Moderno** — Interfaz limpia con estética profesional
- **100% Responsive** — Se adapta a móviles, tablets y escritorio
- **Navegación Fija** — Barra de navegación con efecto blur
- **Secciones** — Inicio, Sobre Mí, Habilidades, Proyectos, Contacto
- **Animaciones Suaves** — Transiciones y hover effects elegantes
- **Código Limpio** — HTML semántico y CSS organizado con variables

## 📦 Uso

1. Clona el repositorio:
   ```bash
   git clone https://github.com/juanruiz85/Portafolio.git
   ```

2. Abre el archivo `index.html` en tu navegador:
   ```bash
   # En macOS
   open index.html

   # En Windows
   start index.html

   # En Linux
   xdg-open index.html
   ```
